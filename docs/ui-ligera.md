# UI ligera

## Reglas base

- No usar MUI ni otro kit pesado por defecto.
- Preferir HTML semantico, CSS propio y componentes pequeños.
- Cargar JavaScript cliente solo para interacciones reales.
- Evitar layouts de marketing; la app empieza en el tablero operativo.
- Mantener radios de 8px o menos.
- Usar colores institucionales con contraste y sin paletas monocromaticas.

## Pantallas prioritarias

1. Dashboard operativo.
2. Solicitudes.
3. Agenda de instancias Meet.
4. Asignacion de asistencia.
5. Historico Zoom.
6. Liquidaciones.

## Criterios de rendimiento

- Componentes de servidor por defecto.
- Formularios progresivos antes que estados globales innecesarios.
- Tablas y listas paginadas desde el servidor.
- Sin icon packs hasta que haya botones/herramientas que los necesiten.
