# Biblioteca de grabaciones y archivos

La búsqueda usa el control nativo `search` y mantiene el envío al presionar Enter. Los filtros se presentan como un grupo de botones con estado `aria-pressed`: cada selección actualiza los mismos parámetros de URL y conserva los conteos existentes.

Los filtros son botones de selección de vista y no pestañas con paneles. Esto permite navegación por teclado nativa y anuncia el estado activo sin exigir el patrón de flechas y paneles de ARIA tabs. No cambian permisos, recursos de Drive ni contratos.
